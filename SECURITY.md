# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting feature when it is enabled. Otherwise contact the repository maintainer privately through an appropriate channel listed on their GitHub profile.

Include enough information to reproduce and assess the issue, but do not include unrelated secrets or personal data.

## Supported versions

Until the project defines a formal release policy, security fixes target the current default branch and the latest supported release, if releases exist.
